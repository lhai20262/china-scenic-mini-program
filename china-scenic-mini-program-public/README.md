# 游迹中国

一款用于浏览、搜索和记录全国景区足迹的微信小程序。

## 主要功能

- 全国 5A、4A、3A 景区及代表性地标搜索
- 按省份和景区等级筛选
- 景区实景图片、介绍、文字讲解与游览路线
- 景区收藏、旅行清单、足迹点亮和到访日期
- 中国景区点亮地图、旅行笔记与评论
- 附近景区、随机目的地和旅行规划

## 技术实现

项目使用微信小程序原生框架开发，主要包括 WXML、WXSS 和 JavaScript。收藏、足迹、笔记等个人数据默认保存在用户本机。

## 使用方法

1. 下载或克隆本仓库。
2. 使用微信开发者工具导入项目根目录。
3. 根据需要在开发者工具中配置自己的小程序 AppID。
4. 编译并预览。

## 数据说明

景区名录是公开资料整理形成的离线快照，不代表官方实时完整名单。景区等级、开放时间、票务和预约信息请以文旅部门及景区官方公告为准。详细数据来源见 [data/README.md](data/README.md)。
