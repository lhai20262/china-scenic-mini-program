# 游迹中国——全国景区探索微信小程序

## 项目简介

“游迹中国”是一款全国景区探索类微信小程序，收录并分类展示全国部分 5A、4A、3A 景区、未评级景点及各省代表性地标。用户可以搜索景区、查看实景图片和文字讲解，也可以收藏景区、记录足迹、点亮景点并制定旅行计划。

## 主要功能

- 全国 5A、4A、3A 景区分类展示与搜索
- 未评级景点及全国各省代表性地标展示
- 景区实景图片、简介和文字讲解
- 景区收藏、游览日期及旅行足迹记录
- 中国景区点亮地图，支持点亮和取消点亮
- 当月推荐景区与随机目的地推荐
- 旅行计划、成就系统及年度旅行报告
- 个性化景区推荐和基础客流趋势提示
- 搜索历史、阅读进度、返回顶部和字体大小调节
- 景区评论展示及页面过渡动画
- 离线旅行包和行程分享码功能

## 运行方法

1. 下载本项目代码，并解压到电脑文件夹。
2. 安装并打开“微信开发者工具”。
3. 使用微信扫码登录开发者工具。
4. 点击“导入项目”。
5. 选择解压后的项目文件夹。
6. 填写自己的微信小程序 AppID；如果仅用于测试，也可以选择测试号。
7. 确认项目目录中包含 `app.js`、`app.json` 和 `app.wxss`。
8. 点击“导入”，进入项目后点击顶部的“编译”即可运行。

## 技术说明

本项目使用微信小程序原生框架开发，主要采用 WXML、WXSS 和 JavaScript。景区数据及文字内容保存在项目本地，收藏、足迹、点亮状态和搜索历史主要使用微信本地缓存保存。

## 注意事项

- 本项目已取消 MP3 和语音讲解功能，目前使用文字讲解。
- 部分图片为网络图片，运行时需要保持网络连接。
- 客流趋势为日期规则生成的参考提示，并非景区实时客流数据。
- 用户数据主要保存在本机，清除微信缓存后可能丢失。
